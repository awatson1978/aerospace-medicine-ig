# research/

Source documents for the NASA Medical Requirements questionnaires (MEDB and MR series)
and related aerospace-medicine background reading. These PDFs are reference material for
authors; they are not part of the published Implementation Guide and are not copied into
the site. The questionnaires derived from them are in `input/fsh/questionnaires/` and cite
the NASA Life Sciences Data Archive MRID library through `meta.source`.

Files retain their original NASA LSDA download names. `input/references/` holds
additional whitepapers referenced from the References page.
